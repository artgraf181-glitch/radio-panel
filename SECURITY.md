# Zgłaszanie problemów bezpieczeństwa

Nie publikuj w zgłoszeniu tokenów dostępu, podpisanych adresów Home Assistanta, pełnych logów zawierających prywatne adresy ani danych konta.

Problem bezpieczeństwa zgłoś prywatnie właścicielowi repozytorium przez funkcję **Private vulnerability reporting** na GitHubie, jeśli jest włączona. W przeciwnym razie utwórz krótkie zgłoszenie bez szczegółów podatności i poproś o bezpieczny kanał kontaktu.
